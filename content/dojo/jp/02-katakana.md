# Katakana カタカナ dan kata serapan

## §1 Fungsi katakana
- **Kata serapan** dari bahasa asing: コーヒー (kopi), パソコン (PC), フロントエンド.
- **Nama asing dan nama perusahaan**: ファウザン, インドネシア, ミスミ.
- Penekanan atau efek bunyi, seperti huruf miring dalam tulisan Latin.

Di dunia IT Jepang, **sebagian besar istilah teknis adalah katakana**. Menguasai katakana dengan cepat langsung berguna untuk pekerjaanmu.

## §3 Pasangan yang paling sering tertukar

| Pasangan | Cara membedakan |
|---|---|
| **シ shi / ツ tsu** | シ: dua titik **di kiri**, garis panjang naik dari **bawah**. ツ: titik **di atas**, garis turun dari **atas** |
| **ソ so / ン n** | ソ: garis panjang turun dari **atas**. ン: naik dari **bawah** (seperti シ dan ツ) |
| ク / ケ / タ | ケ punya garis mendatar yang menembus ke kanan. タ punya garis kecil di dalam |
| ワ / ウ / フ | ウ punya garis kecil di atas. フ tanpa garis tegak di kiri |
| ノ / メ | メ punya garis silang |
| チ / テ | チ: garis atas miring. テ: dua garis mendatar |
| ア / マ | マ lebih lebar, dengan coretan kecil di bawah |
| ユ / コ | ユ: garis bawahnya memanjang ke kiri |
| ヌ / ス | ヌ punya garis kecil menyilang |

## §4 Garis panjang ー
Dalam katakana, vokal panjang ditulis dengan **ー**: コーヒー (kōhī), サーバー (sābā), ユーザー (yūzā).

## §5 Kombinasi khusus untuk bunyi asing

| Tulisan | Bunyi | Contoh |
|---|---|---|
| ティ / ディ | ti / di | パーティー (pesta), ディスプレイ |
| トゥ / ドゥ | tu / du | タトゥー |
| ファ フィ フェ フォ | fa fi fe fo | ファイル (file), フォルダ |
| ウィ ウェ ウォ | wi we wo | ウェブ (web), ウィンドウ |
| シェ / ジェ / チェ | she / je / che | シェア (share), ジェイソン (JSON), チェック |
| ヴ | v (sering dibaca b) | ヴァイオリン |

**Pola umum dari bahasa Inggris:**
- Konsonan di akhir kata diberi vokal tambahan (biasanya u, setelah t/d biasanya o): desk → デスク, bed → ベッド, test → テスト.
- "-er" / "-or" di akhir menjadi garis panjang: server → サーバー, user → ユーザー, computer → コンピューター.
- l dan r sama-sama memakai baris ラ: release → リリース.
- "v" sering menjadi baris バ: video → ビデオ, server → サーバー.
