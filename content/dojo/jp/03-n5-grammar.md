# Grammar N5 (56 poin)

Poin `n5-g01`–`n5-g56` dibuka bertahap di jalur 日本語 Section 1 (4 poin per unit). Setiap poin menjadi kartu **grammar recall** di Hari ini.

- Contoh ditulis dengan kana, ditambah kanji N5 yang sudah dipelajari.
- Urutannya mengikuti tema Irodori, tapi **bukan salinan isi Irodori**.

## A. Konjugasi kata kerja

| Grup | Ciri | Contoh |
|---|---|---|
| **1** (godan) | Berakhiran -u (selain kebanyakan -iru/-eru) | かく, のむ, はなす, まつ, かう, いく, あそぶ |
| **2** (ichidan) | Berakhiran **-iru / -eru** | たべる, みる, ねる, おきる |
| **3** (tidak beraturan) | Hanya dua | する, くる |

Pengecualian penting: **かえる** (pulang), **はいる** (masuk), **しる** (tahu), dan **はしる** (lari) berakhiran -eru/-iru tapi termasuk **Grup 1**.

| Kamus | ます | て | た | ない |
|---|---|---|---|---|
| かく | かきます | かいて | かいた | かかない |
| いく | いきます | **いって** (pengecualian) | いった | いかない |
| およぐ | およぎます | およいで | およいだ | およがない |
| はなす | はなします | はなして | はなした | はなさない |
| まつ | まちます | まって | まった | またない |
| かう | かいます | かって | かった | かわない |
| かえる | かえります | かえって | かえった | かえらない |
| のむ | のみます | のんで | のんだ | のまない |
| あそぶ | あそびます | あそんで | あそんだ | あそばない |
| たべる (Grup 2) | たべます | たべて | たべた | たべない |
| みる (Grup 2) | みます | みて | みた | みない |
| する | します | して | した | しない |
| くる | きます | きて | きた | **こない** |
| ある | あります | あって | あった | **ない** |

**Rumus bentuk て Grup 1:**
- う・つ・る → って
- む・ぶ・ぬ → んで
- く → いて (kecuali いく → いって)
- ぐ → いで
- す → して

## B. Partikel inti

| Partikel | Fungsi | Contoh |
|---|---|---|
| は (wa) | Topik: "kalau soal…" | わたしは がくせいです |
| が | Subjek dan fokus info baru; dipakai dengan すき, ある/いる, ほしい | ねこが います |
| を (o) | Objek | コーヒーを のみます |
| に | Titik waktu, tujuan, tempat keberadaan, penerima | しちじに おきます・とうきょうに すんでいます |
| へ (e) | Arah | くうこうへ いきます |
| で | Tempat kegiatan, alat | カフェで べんきょうします・バスで いきます |
| と | Dan (daftar lengkap), bersama | ともだちと いきます |
| も | Juga | わたしも がくせいです |
| の | Milik dan keterangan | わたしの ほん |
| から / まで | Dari / sampai | くじから ごじまで |
| か | Penanda pertanyaan | がくせいですか |
| ね / よ | Mencari persetujuan / memberi info | いいですね・おいしいですよ |

**は vs が, aturan praktis:**
- は memperkenalkan **topik** yang sudah diketahui; yang penting adalah bagian sesudahnya.
- が menandai **siapa/apa** sebagai informasi baru.
- Kata tanya selalu memakai **が** sebagai subjek: だれが きましたか。(Siapa yang datang?)

**Bentuk biasa (g53):**
- kata benda dan sifat な memakai **だ**: がくせいだ / がくせいじゃない / がくせいだった;
- sifat い tetap: たかい / たかくない / たかかった;
- di percakapan santai, だ sering dihilangkan dalam pertanyaan: がくせい？

## D. Kartu recall (contoh format di Dōjō)
- **Depan:** "Tolong jangan …" → **Belakang:** V-ないで ください (g51)
- **Depan:** "Pernah …" → **Belakang:** V-た ことが あります (g49)
- **Depan:** はなす → bentuk て? → **Belakang:** はなして
- **Depan:** いく → bentuk て? → **Belakang:** いって (pengecualian)
- **Depan:** Partikel tempat **kegiatan**? → **Belakang:** で (bukan に)
