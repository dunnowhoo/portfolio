# Dynamic Programming 2-D

**Ide inti:** state butuh **dua indeks**. Contohnya posisi di dua string (`i, j`), posisi di grid (`r, c`), interval (`l, r`), atau indeks + status. Lima langkah DP 1-D tetap berlaku.

## 1. Pola transisi yang paling sering

| Keluarga | State | Transisi |
|---|---|---|
| Grid path | `dp[r][c]` | dari atas dan kiri |
| Dua string (LCS, Edit) | `dp[i][j]` = jawaban untuk `a[i:]`, `b[j:]` | huruf sama → diagonal; beda → pilihan |
| Knapsack kombinasi | `dp[a]` dengan loop koin di luar | `dp[a] += dp[a − c]` |
| State machine | `dp[i][state]` | transisi antar-state per hari |
| Interval | `dp[l][r]` | pilih k di tengah sebagai elemen terakhir/pemisah |

## 2. Grid: Unique Paths
```python
def unique_paths(m, n):
    row = [1] * n                       # baris paling atas: 1 cara ke setiap sel
    for _ in range(1, m):
        for c in range(1, n):
            row[c] += row[c - 1]        # atas (row[c] lama) + kiri (row[c-1] baru)
    return row[-1]
```

## 3. Dua string
**Longest Common Subsequence:**
```python
def lcs(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]      # dp[i][j] = LCS dari a[i:], b[j:]
    for i in range(m - 1, -1, -1):
        for j in range(n - 1, -1, -1):
            if a[i] == b[j]:
                dp[i][j] = 1 + dp[i + 1][j + 1]
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j + 1])
    return dp[0][0]
```

**Edit Distance:**
```python
def min_distance(a, b):
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][n] = m - i                  # b habis → hapus sisa a
    for j in range(n + 1):
        dp[m][j] = n - j                  # a habis → sisipkan sisa b
    for i in range(m - 1, -1, -1):
        for j in range(n - 1, -1, -1):
            if a[i] == b[j]:
                dp[i][j] = dp[i + 1][j + 1]
            else:
                dp[i][j] = 1 + min(dp[i + 1][j],      # hapus a[i]
                                   dp[i][j + 1],      # sisip b[j]
                                   dp[i + 1][j + 1])  # ganti
    return dp[0][0]
```

**Distinct Subsequences** (berapa cara t muncul sebagai subsequence s):
```python
def num_distinct(s, t):
    m, n = len(s), len(t)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][n] = 1                      # t kosong: satu cara
    for i in range(m - 1, -1, -1):
        for j in range(n - 1, -1, -1):
            dp[i][j] = dp[i + 1][j]       # lewati s[i]
            if s[i] == t[j]:
                dp[i][j] += dp[i + 1][j + 1]   # pakai s[i]
    return dp[0][0]
```

**Interleaving String:**
```python
def is_interleave(s1, s2, s3):
    m, n = len(s1), len(s2)
    if m + n != len(s3):
        return False
    dp = [[False] * (n + 1) for _ in range(m + 1)]
    dp[m][n] = True
    for i in range(m, -1, -1):
        for j in range(n, -1, -1):
            if i < m and s1[i] == s3[i + j] and dp[i + 1][j]:
                dp[i][j] = True
            if j < n and s2[j] == s3[i + j] and dp[i][j + 1]:
                dp[i][j] = True
    return dp[0][0]
```

## 4. Memo dua indeks (lebih mudah daripada tabel)
**Regular Expression Matching:**
```python
from functools import cache
def is_match(s, p):
    @cache
    def dp(i, j):
        if j == len(p):
            return i == len(s)
        first = i < len(s) and p[j] in (s[i], '.')
        if j + 1 < len(p) and p[j + 1] == '*':
            return dp(i, j + 2) or (first and dp(i + 1, j))   # pakai 0 kali, atau pakai sekali lagi
        return first and dp(i + 1, j + 1)
    return dp(0, 0)
```

**Target Sum:**
```python
def find_target_sum_ways(nums, target):
    @cache
    def ways(i, total):
        if i == len(nums):
            return int(total == target)
        return ways(i + 1, total + nums[i]) + ways(i + 1, total - nums[i])
    return ways(0, 0)
```

**Longest Increasing Path in a Matrix** (DFS + memo, tanpa visited karena jalur naik tidak bisa berputar):
```python
def longest_increasing_path(matrix):
    R, C = len(matrix), len(matrix[0])
    @cache
    def dfs(r, c):
        best = 1
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < R and 0 <= nc < C and matrix[nr][nc] > matrix[r][c]:
                best = max(best, 1 + dfs(nr, nc))
        return best
    return max(dfs(r, c) for r in range(R) for c in range(C))
```

## 5. Kombinasi vs permutasi (Coin Change II)
```python
def change(amount, coins):
    dp = [1] + [0] * amount
    for c in coins:                       # koin di LUAR → urutan tidak dihitung ganda
        for a in range(c, amount + 1):
            dp[a] += dp[a - c]
    return dp[amount]
```
Kalau loop amount di luar dan koin di dalam, yang dihitung adalah **permutasi** (1+2 dan 2+1 dihitung berbeda).

## 6. State machine (Stock with Cooldown)
```python
def max_profit(prices):
    hold, sold, rest = float('-inf'), 0, 0
    for p in prices:
        hold, sold, rest = (max(hold, rest - p),   # tetap pegang, atau beli dari rest
                            hold + p,              # jual hari ini
                            max(rest, sold))       # istirahat (cooldown selesai)
    return max(sold, rest)
```

## 7. Interval DP (Burst Balloons, Hard)
Trik utamanya: pilih balon `k` yang pecah **terakhir** di interval `(l, r)`. Saat itu, tetangganya pasti `l` dan `r`.
```python
def max_coins(nums):
    a = [1] + nums + [1]
    n = len(a)
    dp = [[0] * n for _ in range(n)]      # dp[l][r] = koin maksimum dari balon di antara l dan r (eksklusif)
    for length in range(2, n):
        for l in range(0, n - length):
            r = l + length
            for k in range(l + 1, r):
                dp[l][r] = max(dp[l][r], a[l] * a[k] * a[r] + dp[l][k] + dp[k][r])
    return dp[0][n - 1]                   # O(n³)
```

## 8. Jebakan
- Indeks off-by-one karena tabel berukuran `(m+1) × (n+1)`. Tulis arti `dp[i][j]` di komentar.
- Coin Change II: urutan loop menentukan kombinasi vs permutasi.
- Memo dengan argumen list → harus diubah ke tuple atau memakai indeks.
- Burst Balloons: memilih balon yang pecah **pertama** membuat submasalah saling bergantung. Pilih yang **terakhir**.

## 9. Kartu review
- **T:** LCS saat huruf beda? **J:** `max(dp[i+1][j], dp[i][j+1])`.
- **T:** Edit distance, tiga operasi? **J:** Hapus `(i+1, j)`, sisip `(i, j+1)`, ganti `(i+1, j+1)`.
- **T:** Coin Change II, loop apa di luar? **J:** Koin.
- **T:** Stock Cooldown, tiga state? **J:** hold, sold, rest.
- **T:** Burst Balloons, ide kunci? **J:** Balon k pecah terakhir di interval (l, r).
