# Dynamic Programming 1-D

**Ide inti:** DP = rekursi + **memo** untuk submasalah yang **berulang**. Yang sulit bukan kodenya, tapi **mendefinisikan state** dengan tepat.

## 1. Lima langkah (tulis di catatan sebelum coding)
1. **State:** `dp[i]` artinya apa? Satu kalimat yang presisi. Contoh: "uang maksimum dari rumah 0..i".
2. **Transisi:** bagaimana `dp[i]` dibangun dari state yang lebih kecil?
3. **Base case:** nilai state terkecil.
4. **Urutan:** isi tabel dalam urutan yang menjamin state yang dibutuhkan sudah dihitung.
5. **Jawaban:** `dp[n]`, `dp[0]`, atau `max(dp)`?

Mulai dari **rekursi + `@cache`** (paling alami), lalu ubah ke tabel kalau perlu, lalu hemat memori kalau hanya butuh beberapa state terakhir.

## 2. Sinyal
- "Jumlah **cara**", "nilai **minimum/maksimum**", "**apakah mungkin**"
- Pilihan di setiap langkah memengaruhi pilihan berikutnya (ambil/lewati, potong di sini/di sana)
- Greedy terasa benar tapi ada contoh yang membantahnya

## 3. Keluarga A: Fibonacci-like (bergantung pada 1–2 state sebelumnya)
```python
def climb_stairs(n):
    a, b = 1, 1                    # dp[0], dp[1]
    for _ in range(n - 1):
        a, b = b, a + b
    return b

def rob(nums):                     # House Robber
    prev2 = prev1 = 0              # dp[i-2], dp[i-1]
    for x in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + x)   # lewati vs ambil
    return prev1

def rob_circle(nums):              # House Robber II
    if len(nums) == 1:
        return nums[0]
    return max(rob(nums[1:]), rob(nums[:-1]))          # rumah pertama dan terakhir tidak boleh bersama
```

## 4. Keluarga B: decode dan partisi string
```python
def num_decodings(s):
    n = len(s)
    dp = [0] * (n + 1)
    dp[n] = 1                              # string kosong: satu cara
    for i in range(n - 1, -1, -1):
        if s[i] == '0':
            continue                       # tidak ada huruf yang diawali 0
        dp[i] = dp[i + 1]                  # ambil 1 digit
        if i + 1 < n and int(s[i:i + 2]) <= 26:
            dp[i] += dp[i + 2]             # ambil 2 digit (10..26)
    return dp[0]

def word_break(s, word_dict):
    words, n = set(word_dict), len(s)
    dp = [False] * (n + 1)
    dp[n] = True
    for i in range(n - 1, -1, -1):
        dp[i] = any(s.startswith(w, i) and dp[i + len(w)] for w in words)
    return dp[0]
```

## 5. Keluarga C: knapsack
**Unbounded** (koin boleh diulang), contohnya Coin Change:
```python
def coin_change(coins, amount):
    INF = amount + 1
    dp = [0] + [INF] * amount              # dp[a] = koin minimum untuk a
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a:
                dp[a] = min(dp[a], dp[a - c] + 1)
    return dp[amount] if dp[amount] != INF else -1
```

**0/1 subset sum** (setiap angka sekali), contohnya Partition Equal Subset Sum:
```python
def can_partition(nums):
    total = sum(nums)
    if total % 2:
        return False
    target = total // 2
    reachable = {0}
    for x in nums:
        reachable |= {r + x for r in reachable if r + x <= target}
    return target in reachable
```
Versi array: `dp[t] |= dp[t − x]` dengan loop **t dari besar ke kecil** supaya setiap angka hanya dipakai sekali.

## 6. Keluarga D: subsequence
**Longest Increasing Subsequence**, O(n²) yang mudah dijelaskan:
```python
def lis_quadratic(nums):
    dp = [1] * len(nums)                   # dp[i] = LIS yang BERAKHIR di i
    for i in range(len(nums)):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    return max(dp)
```

O(n log n) dengan *patience sorting*:
```python
import bisect
def lis(nums):
    tails = []                             # tails[k] = ekor terkecil untuk LIS panjang k+1
    for x in nums:
        i = bisect.bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)
```

## 7. Keluarga E: max/min berjalan (Maximum Product Subarray)
Angka negatif membalik yang terbesar menjadi yang terkecil, jadi simpan **keduanya**.
```python
def max_product(nums):
    res = max(nums)
    cur_max = cur_min = 1
    for x in nums:
        cand = (x, x * cur_max, x * cur_min)
        cur_max, cur_min = max(cand), min(cand)
        res = max(res, cur_max)
    return res
```

## 8. Palindrom: perluas dari tengah (lebih sederhana daripada DP 2D)
```python
def longest_palindrome(s):
    best = ""
    for center in range(2 * len(s) - 1):   # pusat ganjil (huruf) dan genap (celah)
        l = center // 2
        r = l + center % 2
        while l >= 0 and r < len(s) and s[l] == s[r]:
            l -= 1; r += 1
        if r - l - 1 > len(best):
            best = s[l + 1:r]
    return best
```
Palindromic Substrings memakai pola yang sama, hanya menghitung setiap perluasan yang berhasil.

## 9. Jebakan
- State ambigu ("LIS sampai i" vs "LIS yang **berakhir** di i") menghasilkan transisi yang salah.
- Coin Change: inisialisasi `float('inf')` lalu lupa mengembalikan −1.
- Decode Ways: "06" tidak valid, dan `'0'` sendirian tidak bisa didekode.
- Subset sum dengan array: loop naik membuat angka terpakai berkali-kali.

## 10. Kartu review
- **T:** House Robber, transisinya? **J:** `max(dp[i−1], dp[i−2] + nums[i])`.
- **T:** Coin Change, state? **J:** `dp[a]` = koin minimum untuk jumlah a.
- **T:** LIS O(n log n)? **J:** Array `tails` + `bisect_left`.
- **T:** Maximum Product, kenapa simpan min? **J:** Negatif × negatif menjadi positif besar.
- **T:** 0/1 knapsack dengan array 1D, arah loop? **J:** Dari besar ke kecil.
